# 🌸 Iris ML — Hyperparameter Tuning & Ensemble Learning

> A hands-on machine learning project using the Iris dataset to explore
> classification, hyperparameter tuning, and ensemble learning.

## 🎯 Project Overview

This project explores machine learning classification using the Iris dataset.

The main focus of this project is understanding how different machine
learning techniques and hyperparameter tuning can improve model performance.

## 🧠 Machine Learning Techniques

- K-Nearest Neighbors (KNN)
- Hyperparameter Tuning
- GridSearchCV
- Ensemble Learning
- Bagging
- Boosting
- Stacking

## 🔍 Hyperparameter Tuning

GridSearchCV is used to search for the best combination of model
hyperparameters using cross-validation.

This helps select a better-performing model instead of choosing
hyperparameters manually.

## 🤝 Ensemble Learning

This project also explores different ensemble learning approaches:

### Bagging

Bagging combines multiple models to improve stability and reduce
overfitting.

### Boosting

Boosting builds models sequentially, where each new model focuses on
improving the previous models.

### Stacking

Stacking combines predictions from multiple machine learning models
using another model as a final estimator.

## 📊 Model Evaluation

The models are evaluated using appropriate classification metrics and
their performance is compared to identify effective approaches.
